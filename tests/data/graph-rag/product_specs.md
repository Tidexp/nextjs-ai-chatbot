# Product Specifications: Orion X100

Manufacturer: Helios Robotics
Deployment: Mars Habitat Alpha (2024)

Dependencies:

- Athena Controller (compatible)
- Apollo Firmware v2.1 (required)

Summary:
The Orion X100 manipulator is designed for low-gravity construction tasks.
Helios Robotics partnered with the Mars Habitat Authority for a pilot in 2024.
Athena Controller manages kinematics; Apollo Firmware v2.1 enables radiation-hardened IO.

Caveats:

- Requires field-calibration in situ.
- Not compatible with legacy Hermes modules.
